# oa

Python facade to OpenAi functionality.

### Modules

| [`ask`](oa.ask.html.md#module-oa.ask)                           | Access to already made prompt functions                                         |
|----------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------|
| [`audio`](oa.audio.html.md#module-oa.audio)                       | OpenAI Audio tools                                                              |
| [`base`](oa.base.html.md#module-oa.base)                         | Base oa functionality                                                           |
| [`batch_embeddings`](oa.batch_embeddings.html.md#module-oa.batch_embeddings) | Simplified interface for computing embeddings in bulk using OpenAI's batch API. |
| [`batches`](oa.batches.html.md#module-oa.batches)                   | Batch functionality                                                             |
| [`chats`](oa.chats.html.md#module-oa.chats)                       | Tools to work with shared chats (conversations).                                |
| [`oa_types`](oa.oa_types.html.md#module-oa.oa_types)                 | Types for oa                                                                    |
| [`openai_specs`](oa.openai_specs.html.md#module-oa.openai_specs)         | Tools to extract specs from the openai interface                                |
| [`stores`](oa.stores.html.md#module-oa.stores)                     | Data object layers for openai resources                                         |
| [`tools`](oa.tools.html.md#module-oa.tools)                       | Interface tools                                                                 |
| [`util`](oa.util.html.md#module-oa.util)                         | oa utils                                                                        |
| [`vector_stores`](oa.vector_stores.html.md#module-oa.vector_stores)       | Vector stores and search                                                        |
