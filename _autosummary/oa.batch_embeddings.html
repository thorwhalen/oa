oa.batch_embeddings¶

Simplified interface for computing embeddings in bulk using OpenAI’s batch API.

This module provides a clean, reusable interface for generating embeddings from text segments using OpenAI’s batch API, handling the async nature of the API and providing status monitoring, error handling, and result aggregation.

class oa.batch_embeddings.ProcessingMall(*, current=None, segments=None, finished=None, erred=None, embeddings=None)[source]¶

Bases: Mapping

Container for all stores needed during batch processing.

The ProcessingMall contains five stores, all keyed by batch_id:

  • current: Batches that are currently being processed

  • segments: The text segments corresponding to each batch

  • finished: Completed batches

  • erred: Batches that encountered errors

  • embeddings: The computed embeddings for each batch

oa.batch_embeddings.compute_embeddings(segments, model='text-embedding-3-small', *, batch_size=1000, poll_interval=5.0, max_polls=None, verbosity=1, processing_mall=None, keep_processing_info=False, dacc=None, return_process=False, logger=None, **embeddings_kwargs)[source]¶

Compute embeddings for text segments using OpenAI’s batch API.

This function manages the complete lifecycle of batch embedding requests, from submitting batches to the API, monitoring their status, and aggregating the results.

Parameters:

  • segments (Union[list[str], dict[str, str]]) – Text segments to embed, either as a list or a dictionary

  • model (str) – OpenAI embedding model to use

  • batch_size (int) – Maximum number of segments per batch

  • poll_interval (float) – Seconds between status checks

  • max_polls (int | None) – Maximum number of status checks before timing out

  • verbosity (int) – Level of logging detail (0-2)

  • processing_mall (ProcessingMall | None) – Optional custom ProcessingMall

  • keep_processing_info (bool) – Whether to keep mall data after completion

  • dacc (OaDacc | None) – Optional custom OaDacc instance

  • return_process (bool) – If True, return the EmbeddingsBatchProcess object instead of results

  • logger (Logger | None) – Optional custom logger

  • **embeddings_kwargs – Additional parameters for embedding generation

Returns:

Tuple of (segments, embeddings) If return_process is True:

EmbeddingsBatchProcess object for further interaction

Return type:

tuple[list[str], list[list[float]]] | EmbeddingsBatchProcess
